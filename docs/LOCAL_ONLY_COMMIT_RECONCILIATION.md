## Decisions outside this selective port

1. **Staff MFA/auth convergence:** The August design requires AAL2 for staff browser sessions, while the current backend has no MFA endpoints and the current frontend still contains MFA calls. Reusing its SQL is impossible because migration `0029` has a different immutable meaning. A new migration and a reviewed policy for local and Google/OIDC sessions, enrollment/recovery, and portal boundaries are needed if mandatory staff MFA is selected. Until then, do not claim AAL2 enforcement.
2. **Development/production RDS CA input:** Decide whether those profiles should adopt the staging single-root input or another reviewed delivery mechanism. Do not reintroduce the old two-part global bundle as an unreviewed production source change.

The AWS dependency audit is an independent release gate: the official `aws-cdk-lib` package currently bundles vulnerable `brace-expansion@5.0.9`. No audit exception, override, or repackaging was used.
